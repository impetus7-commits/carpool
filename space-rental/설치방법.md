# 학교 공간 대여 — 설치 방법

구글시트 한 개와 그 시트에 묶인 앱스크립트로 움직입니다. 처음 한 번만 아래 순서대로 하면 됩니다.

> **꼭 학교 Workspace 계정으로 진행하세요.** 개인 Gmail 계정으로 만들면 로그인한 사람의 이메일을 확인할 수 없어 아무도 신청하지 못합니다.

## 1. 구글시트 만들기
1. 학교 계정으로 [구글시트](https://sheets.new)를 새로 만들고 이름을 "공간 대여"처럼 붙입니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.

## 2. 코드 붙여 넣기
앱스크립트 편집기에서 파일을 아래 이름으로 만들고, 이 폴더의 같은 이름 파일 내용을 그대로 붙여 넣습니다.

| 편집기에서 만들 파일 | 종류 | 붙여 넣을 내용 |
|---|---|---|
| `Code` | 스크립트 | `Code.gs` (처음부터 있는 `Code.gs`의 내용을 지우고 붙여 넣기) |
| `Logic` | 스크립트 | `Logic.gs` |
| `Store` | 스크립트 | `Store.gs` |
| `Setup` | 스크립트 | `Setup.gs` |
| `index` | **HTML** | `index.html` (이름은 `index`만 입력. `index.html.html`이 되지 않게 주의) |

`dev/`, `tests/`, `preview.html`은 올리지 않습니다. 저장(Ctrl+S)합니다.

## 3. 처음 설정 실행
1. 편집기 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다.
2. 권한을 묻는 창이 나오면 학교 계정을 고르고 허용합니다.
3. 편집기 아래쪽 **실행 로그**에 "설정이 끝났습니다. 탭: 공간, 사용자, …"와 **구글시트 주소**가 나옵니다. 그 주소의 시트를 열면 `공간`, `사용자`, `교시`, `예약`, `기록`, `설정` 탭이 만들어져 있습니다.
   실행한 본인은 `사용자` 탭에 관리자로 자동 등록됩니다.
4. 실행 로그에 빨간 오류가 나오면 탭이 만들어지지 않습니다. 아래 "자주 생기는 문제"를 확인하세요.

> script.google.com 에서 프로젝트를 따로 만든 경우에는 연결된 시트가 없으므로, `setup`이 "학교 공간 대여"라는 시트를 내 드라이브에 새로 만들어 연결합니다. 이때는 처음에 만들어 둔 빈 시트가 아니라 **실행 로그에 나온 주소의 시트**를 쓰게 됩니다.

## 4. 학교에 맞게 고치기
- **`설정`**: 학교이름, 안내문, 예약가능일수, 반복예약최대일수
- **`교시`**: 교시 이름과 시작·종료 시각. 줄 순서가 화면 순서입니다. `ID`는 겹치지 않게 아무 글자나 쓰면 되고, 한번 쓴 ID는 바꾸지 마세요.
- **`공간`**: 한 줄이 공간 한 곳입니다.

| 열 | 적는 법 |
|---|---|
| ID | 겹치지 않는 짧은 글자 (예: `A201`). 예약이 생긴 뒤에는 바꾸지 마세요 |
| 건물, 층 | 예: `본관`, `3`. 지하는 `B1` |
| 순서 | 복도 왼쪽부터 1, 2, 3 … 배치도에 이 순서로 놓입니다 |
| 수용인원 | 숫자만 |
| 용도, 시설 | 쉼표로 구분 (예: `회의, 토론, 발표`). 추천 화면의 선택 버튼이 됩니다 |
| 특이사항, 소개 | 자유롭게 |
| 사진 | 사진 주소. 여러 장은 쉼표로 구분 |
| 영상 | 유튜브 주소 또는 구글 드라이브 영상 주소 |
| 신청가능 | `Y` 또는 `N`. 교무실·계단처럼 배치도에만 보일 곳은 `N` |

- **`사용자`**: 신청을 허용할 계정을 등록합니다. 이메일, 이름, 역할(`교직원`·`학생`·`관리자`), 소속(부서나 학년·반). 명단을 엑셀에서 복사해 붙여 넣어도 됩니다.

### 사진과 영상 넣기
- 사진을 구글 드라이브에 올리고 **공유 → 링크가 있는 모든 사용자(뷰어)**로 바꾼 뒤 링크를 `사진` 칸에 붙입니다. 공유를 제한해 두면 화면에 사진이 보이지 않을 수 있습니다.
- 영상은 유튜브에 "일부 공개"로 올리고 주소를 붙이는 방법이 가장 안정적입니다.

## 5. 웹앱 배포
1. 앱스크립트 편집기 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 다음 사용자 인증 정보로 실행: **나**
4. 액세스 권한이 있는 사용자: **(학교 도메인) 내의 모든 사용자**
5. **배포**를 누르면 나오는 웹 앱 URL을 교직원·학생에게 안내합니다.

"나"로 실행하므로 사용자에게 시트를 공유할 필요가 없습니다. **시트는 관리자끼리만 공유하세요.** 그래야 기록을 아무나 고칠 수 없습니다.

## 6. 코드를 고친 뒤에는
**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 주소가 그대로 유지되면서 반영됩니다.
시트의 내용(공간·사용자·교시·설정)을 고친 것은 다시 배포하지 않아도 바로 반영됩니다.

## 사용 규칙 요약
- 교직원·관리자 신청은 바로 확정, 학생 신청은 관리자가 승인해야 확정됩니다.
- 같은 공간·날짜·교시에는 한 건만 들어갑니다. 승인 대기 중인 신청도 자리를 잡고 있습니다.
- 반복 예약은 시작일부터 종료일까지 고른 요일마다 만들어집니다. 이미 예약이 있는 날은 목록을 보여 주고 빼고 신청할지 묻습니다.
- 정규 수업으로 쓰는 시간은 관리자가 반복 예약으로 미리 막아 두세요.
- 신청·수정·취소·승인·반려는 모두 `기록` 탭에 변경 전후와 함께 남습니다. 관리 화면의 **기록**에서도 볼 수 있습니다.
- 취소한 예약은 지워지지 않고 `예약` 탭에 상태가 `취소`로 남습니다.

## 자주 생기는 문제
| 증상 | 원인과 해결 |
|---|---|
| "로그인한 계정을 확인할 수 없어요" | 배포한 계정과 접속한 계정의 도메인이 다릅니다. 학교 계정으로 배포하고 학교 계정으로 접속하세요 |
| "등록되지 않은 계정" | `사용자` 탭에 그 이메일이 없습니다. 철자와 앞뒤 공백을 확인하세요 |
| "index라는 HTML 파일을 찾을 수 없습니다" | HTML 파일 이름이 정확히 `index`인지 확인하세요 |
| "'공간' 탭이 없어요" | 3번의 `setup`을 실행하지 않았습니다 |
| `setup`을 실행했는데 탭이 없음 | ① 함수 목록에서 `setup`이 아닌 다른 함수(`doGet` 등)를 실행했거나 ② 권한 허용 창을 닫았거나 ③ 실행 로그에 빨간 오류가 있습니다. 또는 ④ 탭이 다른 시트에 만들어졌습니다 — 실행 로그의 "구글시트 주소"를 여세요 |
| "구문 오류(SyntaxError)" | `index.html` 내용을 스크립트 파일에 붙였거나, 한 파일에 두 파일 내용을 함께 붙였습니다. 파일 5개를 각각 따로 만드세요 |
| 고친 코드가 반영되지 않음 | 6번처럼 새 버전으로 다시 배포하세요 |

## 미리보기와 테스트 (개발용)
- `preview.html`을 브라우저로 열면 구글 없이 예시 데이터로 화면을 써 볼 수 있습니다. 위쪽 띠에서 관리자·교직원·학생·미등록 계정을 바꿔 볼 수 있고, 데이터는 그 브라우저에만 저장됩니다.
- `npm test`로 서버 규칙 테스트를, `npm run preview`로 `preview.html` 다시 만들기를 실행합니다.

## 기존 사용 대장 옮기기 (선택)
엑셀로 쓰던 "교실 사용 대장"이 있으면 `dev/make-import.py`로 일회용 스크립트 `Import.gs`를 만들어 옮길 수 있습니다.

```bash
python3 dev/make-import.py Import.gs 대장1.xlsx 대장2.xlsx 대장3.xlsx
```

1. 앱스크립트 편집기에서 스크립트 파일 `Import`를 만들고 `Import.gs` 내용을 붙여 넣습니다.
2. 함수 목록에서 `importLedger`를 골라 실행합니다.
3. 실행 로그에 "공간 ○곳, 예약 ○건을 옮겼습니다"가 나오면 끝입니다.

- 처음 실행하면 `공간` 탭의 예시 공간을 `공간_백업_…` 탭으로 복사해 두고 실제 공간으로 바꿉니다.
- 여러 번 실행해도 같은 내용이 두 번 들어가지 않습니다.
- `Import.gs`에는 사용 내역(이름 포함)이 들어 있으므로 저장소에 올리지 않습니다(`.gitignore`에 등록됨).
